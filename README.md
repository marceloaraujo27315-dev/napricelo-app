# Napricelo Campo
Aplicativo web de campo para cadastro de equipamentos, execução de POPs e histórico local.

## Publicação
Os arquivos deste pacote devem ficar na raiz do repositório GitHub Pages.

## Observação
Os registros desta primeira versão ficam armazenados no próprio navegador/dispositivo (localStorage). Exporte periodicamente o arquivo JSON pelo botão **Exportar registros**.
