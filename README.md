# Napricelo Campo V2

Versão 2 com:
- seleção automática de equipamento cadastrado nos POPs;
- nova aba Coleta / Análise;
- registro de pH, temperatura, data, horário e responsável técnico;
- ponto de coleta;
- aspecto visual e odor;
- parâmetros laboratoriais opcionais: DBO, DQO, sólidos sedimentáveis, óleos e graxas;
- histórico separado de equipamentos, manutenções e análises;
- visualização de detalhes e exclusão de registros;
- exportação em JSON.
